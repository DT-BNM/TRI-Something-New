Capability Building

Workshops

One connected learning journey delivered across October 2026 — each workshop builds a core capability that units apply directly to their competition solution. The Cyclistic rider-analysis dataset is used as the shared teaching example for Data Analytics and Power BI, giving everyone a common dataset to practise on before applying their skills to their own unit's BAU problem.

October (Week 1)

Vibe Coding

Learn to prompt effectively and use AI to support coding, exploration and troubleshooting — supporting problem understanding, preparation, coding and exploration for your unit's solution.

October (Week 2)

Data Analytics

Prepare data, structure the analysis and identify meaningful patterns using the Cyclistic case as a guided example — providing a documented approach your unit can apply to its own data.

October (Weeks 3–4)

Power BI

Turn analysis into clear visualisations and interactive storytelling using the Cyclistic dataset for practice — enabling units that choose a dashboard-based solution to build an effective, user-friendly output.

Unit-Based Challenge

Competition

Rather than working on a shared external case, each TRI unit will identify a genuine business-as-usual (BAU) challenge within their own function and develop a working solution using the capabilities learned across the workshop series — for example a Python-based automation, a Power BI dashboard, a Power App, or another practical tool.

Central Challenge Statement

"How can our unit use Vibe Coding, Data Analytics and/or Power BI to solve a real BAU problem more effectively?"

Beginner-Friendly

Start From What You Know

Teams start from a problem they already understand deeply — their own BAU — which lowers the barrier to entry compared to an unfamiliar external case.

Challenging

Real-World Complexity

Real BAU processes and data are often messy and organisation-specific. Teams must genuinely diagnose and solve the problem rather than apply a template.

Practical

Built to Last

Every solution addresses a real need within the unit, so the output has a genuine chance of continuing to be used after the Eduthon ends.

Transferable

Mirrors Real TRI Work

The work mirrors TRI activities such as automating routine tasks, analysing performance, identifying trends and exceptions, and translating findings into decisions.
