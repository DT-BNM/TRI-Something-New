Workshops

Unit-Based Challenge

Competition

Each TRI unit identifies a real BAU challenge in their own function and builds a working solution with the skills learned — a Python automation, an interactive dashboard, a Power App, or another practical tool.

Central Challenge Statement

"How can our unit use Vibe Coding, Data Analytics and/or Data Visualisation to solve a real BAU problem more effectively?"

Beginner-Friendly

Start From What You Know

Teams start from a problem they already understand — their own BAU — lowering the barrier to entry.

Challenging

Real-World Complexity

Real BAU data is messy and organisation-specific, so teams must genuinely diagnose the problem rather than apply a template.

Practical

Built to Last

Every solution meets a real need, so it has a genuine chance of being used after the Eduthon ends.

Transferable

Mirrors Real TRI Work

The work mirrors real TRI activities — automating tasks, analysing performance, and turning findings into decisions.
